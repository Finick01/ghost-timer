# Ghost Timer para Android

App de Android que abre Ghost Timer a pantalla completa, elige videos de la galería
y guarda el video exportado en la galería (Movies/GhostTimer).

Se compila sin Gradle con `build.sh` (aapt2, ecj, d8 y apksigner en `tools/`, que no se suben).
La llave de firma (`ghosttimer-release.jks`) NO está en este repositorio: guardala aparte,
hace falta la misma llave para publicar actualizaciones.
